# CãoCat 🐶🐱

Pequeno projeto desenvolvido junto ao professor Eliel Cruz de uma pet shop, com seções de apresentação, galeria de fotos, localização e formulário de contato.

## Sobre

A CãoCat Pet Shop tem como proposta oferecer produtos de qualidade para cães e gatos — rações, petiscos, brinquedos, acessórios e itens de higiene — com foco no bem-estar dos pets e na praticidade para os tutores.

## Estrutura do site

O site é uma página única (`index.html`) dividida nas seguintes seções:

- **Header** — logo e menu de navegação (`Sobre`, `Galeria`, `Mapa`, `Contato`)
- **Hero** (`#hero`) — seção de destaque inicial
- **Sobre** (`#about`) — texto de apresentação da loja
- **Galeria** (`#gallery`) — grade de fotos dos produtos/pets
- **Mapa** (`#map`) — mapa incorporado (Google Maps) com a localização
- **Contato** (`#contact`) — formulário com campos de nome, e-mail e mensagem
- **Footer** — direitos autorais e e-mail de contato do desenvolvedor

## Tecnologias

- HTML5
- CSS (`css/style.css`)
- Google Maps Embed API (iframe)
